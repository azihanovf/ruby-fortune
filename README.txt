RUBY FORTUNE CASINO INN — ГОТОВЫЙ СТАТИЧЕСКИЙ САЙТ

1. Откройте index.html в браузере — сайт работает локально.
2. Для публикации загрузите ВСЕ файлы и папку assets/ на статический хостинг,
   сохранив структуру папок. Никаких сборщиков, npm или серверного кода не требуется.
3. Четыре политики доступны через всплывающие окна из подвала сайта.
   Прямые URL страниц политик сохранены для совместимости.
4. Исходные тексты на французском языке перенесены без изменений и сокращений.
5. Фотореалистичные иллюстрации — сгенерированные изображения для оформления;
   они НЕ являются документальными фотографиями реального заведения.

Файлы:
index.html — главная страница
cookie-policy.html — политика cookie
privacy-policy.html — конфиденциальность
terms-conditions.html — условия
responsible-gambling.html — ответственная игра
assets/style.css — дизайн и адаптивная верстка
assets/app.js — мобильное меню и всплывающие окна
assets/*.webp — изображения, хранятся локально
assets/favicon.svg — иконка сайта
